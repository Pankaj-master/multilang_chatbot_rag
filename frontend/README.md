Static frontend for testing chatbot.

How to run:
1. Open frontend/index.html in your browser (file://)
   OR
2. Serve it with a simple static server:
   - npx serve frontend
   - python -m http.server 5500 (from repo root) and open http://localhost:5500/frontend/index.html

Make sure Node backend is running at http://localhost:8001 (update BACKEND in app.js if different).
